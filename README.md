# 🏛️ ระบบแดชบอร์ดงบประมาณและการจัดซื้อจัดจ้าง เทศบาลเมืองศรีสัชนาลัย (ปี 2568 - 2569)

ระบบเว็บแดชบอร์ดติดตามและวิเคราะห์การใช้งบประมาณรายจ่ายและสัญญาจัดซื้อจัดจ้างภาครัฐ (e-GP) ของ **เทศบาลเมืองศรีสัชนาลัย อำเภอศรีสัชนาลัย จังหวัดสุโขทัย** ประจำปีงบประมาณ พ.ศ. 2568 – 2569

---

## 🌟 ฟีเจอร์เด่นของระบบ (Key Features)

- ⚖️ **โหมดเปรียบเทียบ (YoY Comparison):** เปรียบเทียบข้อมูลปี 2568 vs 2569 พร้อมดัชนีชี้วัดการเติบโตของงบประมาณ (+57.36%) และจำนวนโครงการ (+23.61%)
- 💡 **บทวิเคราะห์เชิงลึก 5 มิติ (Strategic Fiscal Insights):**
  1. การขยายตัวของงบประมาณและการลงทุนโครงสร้างพื้นฐานคมนาคม
  2. ปรากฏการณ์กฎพาเรโต 80/20 (e-Bidding เพียง 1.5% ครองเม็ดเงินเกิน 52.7%)
  3. ความคุ้มค่าและการประหยัดงบประมาณ (Value for Money & Cost Savings รวม ฿2.46M)
  4. มิติสวัสดิการสังคม การศึกษา นมโรงเรียน และซ่อมแซมบ้านผู้สูงอายุ-คนพิการ
  5. การกระจายตัวและความโปร่งใสของคู่สัญญา (Top Contractors Leaderboard)
- 🗺️ **แผนที่พิกัดโครงการ (Interactive GIS Map):** ปักหมุดโครงการก่อสร้างถนน คสล. และแอสฟัลต์คอนกรีตที่มีพิกัดจริง 17 จุดในพื้นที่
- 🔍 **ระบบสืบค้นโครงการ (Project Explorer):** ค้นหาทันที (Realtime Instant Search) จาก 1,165 โครงการ พร้อมตัวกรองหลายมิติ และหน้าต่างดูรายละเอียดรายโครงการ
- 🌓 **Dark & Light Mode:** รองรับทั้งธีมมืดและธีมสว่าง คอนทราสต์สูง อ่านง่าย สบายตา
- 📱 **Fully Responsive:** ใช้งานได้ลื่นไหลสมบูรณ์แบบทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน
- 📥 **ส่งออกข้อมูล CSV:** รองรับภาษาไทย (UTF-8 with BOM) เปิดใน Microsoft Excel ได้ถูกต้อง ไม่เป็นภาษาต่างดาว

## 🚀 วิธีเปิดใช้งานบนเครื่อง (Local Run)

1. ดับเบิลคลิกเปิดไฟล์ `start_dashboard.bat` หรือดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานได้ทันที (ไม่ต้องติดตั้งโปรแกรมเพิ่มเติม)
2. หรือรันผ่าน Local Server ด้วย Python:
   ```bash
   python server.py
   ```
   แล้วเข้าใช้งานที่ `http://localhost:8080/`

## 🌐 การนำขึ้น GitHub Pages (วิธีเปิดออนไลน์ให้คนอื่นเข้าดูได้ฟรี)

1. สร้าง Repository ใหม่บน GitHub
2. Push โค้ดทั้งหมดขึ้น branch `main`
3. ไปที่แท็บ **Settings** > **Pages** ของ Repository
4. ในส่วน **Build and deployment** เลือก Source เป็น **Deploy from a branch** และเลือก Branch **`main`** / **`(root)`** แล้วกด **Save**
5. รอ 1-2 นาที จะได้ลิงก์ เช่น `https://<your-username>.github.io/<repo-name>/` สามารถส่งให้เพื่อนเปิดดูได้ทันทีจากทุกอุปกรณ์

## 📁 โครงสร้างไฟล์ในระบบ

- `index.html` — หน้าเว็บแดชบอร์ดหลัก
- `styles.css` — ระบบสไตล์ชีต Responsive, Dark/Light Themes
- `app.js` — ตรรกะประมวลผล กราฟ Chart.js แผนที่ Leaflet และตัวกรอง
- `data.js` — ชุดข้อมูลที่ประมวลผลแล้ว (Zero-CORS Offline Ready)
- `dashboard_data.json` — ฐานข้อมูลโครงสร้าง JSON
- `prepare_data.py` — สคริปต์ประมวลผลและจัดหมวดหมู่ข้อมูล
- `start_dashboard.bat` — ตัวเปิดแดชบอร์ดในคลิกเดียว
